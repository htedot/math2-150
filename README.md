# 数二 · 150 工作台

考研数学二（302）的本地优先学习工作台：**单文件、零依赖、全离线**，双击即用，手机电脑同一份。

👉 **在线版：https://htedot.github.io/math2-150/**

## 里面有什么

| 模块 | 内容 |
| --- | --- |
| 12 章讲义 | 85 节，每节含教材出处、定理与推导、2 道带完整解答的例题、3 条易错点 |
| 题库 | 255 道原创题，按考点铺开，做错自动进错题本 |
| 30 关冲刺 | 不绑日期，按"通关数"推进，过完一轮后用它复检 |
| 全真模考 | 22 题（10 选择 + 6 填空 + 6 解答），满分 150，180 分钟，答题卡 + 自评 + 交卷诊断 |
| 公式速查 | 79 条核心公式，全部 KaTeX 排版 |
| 知识图谱 / 错题回炉 | 掌握度五档刻度，复习间隔按"学习步数"自动安排 |

教材双轨：同济《高等数学》打底，Stewart / Apostol / Spivak 补洞察，并按数二考纲明确裁掉不考内容（级数、三重积分、曲线曲面积分、空间解析几何、概率）。

## 设计上的两个取舍

1. **不绑时间。** 没有倒计时、没有"第几天"。进度刻度是"学完一个单元 / 标记一次掌握度"，日期只作为流水记录。原因是随机学习的节奏比日历表更接近真实。
2. **数据存在你自己的浏览器里。** localStorage，不上传任何服务器（也没有服务器）。换设备用右上角"备份"导出 JSON，在新设备"恢复"。

## 本地使用

直接下载 `index.html` 双击打开即可，功能与在线版完全一致（KaTeX 连字体都内嵌了，不需要网络）。

## 源码

源码在源仓库的 `math2/src/` 下（分片：CSS、数据、12 章讲义、题库、视图层、KaTeX 渲染层），`math2/build.js` 拼成这个单文件，`math2/smoke.js` 渲染自检，`math2/audit.js` 内容体检。此处 `index.html` 是构建产物。
